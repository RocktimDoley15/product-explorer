# Product Explorer

A responsive product browsing web application built as part of the **Cook N Klean Web Development Internship – Week 4 Practical Assignment**.

The application fetches product information from the DummyJSON REST API and allows users to search, filter, and view product details.

## Features

- Fetches product data using the JavaScript Fetch API.
- Displays product images, titles, prices, categories, and ratings.
- Search products by title.
- Filter products by category.
- Reset search and filters.
- View detailed product information in a modal.
- Loading, error, and no-results messages.
- Responsive design for desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- JSON
- Async/Await

## API Used

**DummyJSON Products API**

API Endpoint: https://dummyjson.com/products?limit=100

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you haven't already.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Explore the products in your browser.

An internet connection is required to fetch product data from the API.

## JavaScript Concepts Implemented

- `fetch()` for API requests.
- `async/await` for asynchronous operations.
- `try/catch` for error handling.
- `response.json()` for processing JSON data.
- `filter()` for searching and filtering products.
- DOM manipulation for dynamic rendering.
- `addEventListener()` for user interactions.
